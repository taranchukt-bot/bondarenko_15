# Текстовий квест: місія Редактор

Інтерактивна навчальна гра українською мовою: 15 запитань, 5 рівнів, підказки, бали, звуковий відгук, результат і друк. Не потребує сервера, реєстрації чи бібліотек.

## Публікація на GitHub Pages

1. Увійдіть на https://github.com і створіть репозиторій, наприклад `text-quest` (Public).
2. Завантажте **в корінь репозиторію** файли `index.html`, `style.css`, `script.js` (можна також README.md). Не завантажуйте лише ZIP — його потрібно спочатку розпакувати.
3. Відкрийте **Settings → Pages**.
4. У **Build and deployment → Source** виберіть **Deploy from a branch**.
5. Виберіть гілку **main**, папку **/(root)** і натисніть **Save**.
6. Після публікації сайт буде доступний за адресою `https://ВАШ-ЛОГІН.github.io/text-quest/` (якщо репозиторій названо `text-quest`). Поява сайту може зайняти кілька хвилин.

## Редагування

- Питання, варіанти, відповіді та підказки — у масиві `questions` файлу `script.js`.
- Назви рівнів — у масиві `levels`.
- Кольори та оформлення — у `style.css`.

## Важливо

Питання адаптовано з тесту, створеного під час цієї розмови, а не дослівно витягнуто з інтерактивного зовнішнього ресурсу. Результати не надсилаються вчителю та не збираються на сервері; останній результат зберігається локально у браузері. Для централізованого збору оцінок потрібна окрема інтеграція.
